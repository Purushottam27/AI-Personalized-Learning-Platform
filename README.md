# AI-Personalized-Learning-Platform

Phase 1 MVP of the AI-based personalized learning platform.

## Architecture
- **Frontend:** React 19, TypeScript, Vite, React Router, Tailwind CSS v4
- **Backend:** Node.js 24 LTS, Express 5, JavaScript
- **Database:** MongoDB
- **Architecture:** Modular Monolith

## Local Development
1. **Backend:**
   - `cd backend`
   - `npm install`
   - Create `.env` from `.env.example`
   - `node src/app.js`

2. **Frontend:**
   - `cd frontend`
   - `npm install`
   - `npm run dev`

See the `docs/` folder for complete system design and project requirements.
